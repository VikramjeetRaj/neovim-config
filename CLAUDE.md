# Working rules for this repo

- **Always log changes in `README.md`.** Whenever you modify any file in this
  Neovim config, add an entry to the `## Changelog` section at the bottom of
  `README.md` describing what changed and why. Include the date.
- Keep the rest of the README accurate: if a change affects shortcuts, plugins,
  settings, or tooling, update the relevant section too — not just the changelog.
